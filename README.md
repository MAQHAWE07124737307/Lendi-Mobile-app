# Lendi – Peer-to-Peer Lending App

**Lendi** is an Android mobile application for peer-to-peer lending. Borrowers can request loans and track their status, lenders can view and approve/reject requests, and admins can manage users and monitor the platform.

---

## Features

### Borrower
- Login with role-based authentication
- Request new loans
- View status of active and past loans
- Bottom navigation for easy access to Home, Loans, Requests, Profile

### Lender
- View pending loan requests
- Approve or reject loans

### Admin
- Manage users
- Monitor system statistics

### General
- Vibrant, modern UI with Material Design
- Local database using Room (SQLite)
- MVVM architecture with Kotlin Coroutines
